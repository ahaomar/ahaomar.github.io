          Data Sources & Methodology

          Climate observations

          NASA POWER agroclimatology API — monthly mean temperature (T2M) and corrected precipitation (PRECTOTCORR) at the country's capital coordinates, 1985–2024 (MERRA-2). Values represent a single grid point; regional averages may differ.

          Exposure indicators

          World Bank Open Data API — population, GDP, rural population, arable land and population growth. Also the source of the country list and capital coordinates. CC BY 4.0.

          Vulnerability index

          ND-GAIN Country Index — 2024 scores and ranks, bundled as a static snapshot at build time (190 countries). Higher score = less vulnerable / more ready.

          National commitments

          UNFCCC NDC Registry — direct link to each country's submission. Adaptation priorities are detailed in the country's National Adaptation Plan documents.
