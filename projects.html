08 / 10

Country Climate Profile, open-source generator & browser tool

Independent open-source project · MIT licence

  • Python
  • NASA POWER API
  • World Bank API
  • Chart.js
  • Static site

A tool that turns one country name into a cited climate risk brief: 40 years of NASA temperature and rainfall observations, World Bank exposure indicators and the ND-GAIN vulnerability index, assembled into a three-to-six page profile with charts and a numbered source list. Ships two ways — as a ZCode skill that generates PDF and Word documents, and as the interactive browser edition on this site, where the profile is computed live and exportable to PDF.

github.com/ahaomar/climate-profile-generator → Try the browser edition →

Detail

Contribution
Designed and built the full pipeline: data layer fetching NASA POWER monthly point observations and five World Bank indicators, ND-GAIN index parsing, chart generation, and deterministic document renderers for PDF and Word. Every printed figure traces to a fetched record; anything unavailable is recorded as a stated gap rather than estimated.
Hard problem
Honest data under real-world conditions: single grid points versus regional averages, indicator deprecations, snapshot formats that change without notice, and a report layout that must hold together when a dataset is missing.
Edition on this site
The browser edition fetches the same sources live on each profile generation, computes all narrative figures from the same rows the charts render, and exports to PDF through a dedicated print stylesheet. Open the tool.

09 / 10

un-editorial-check, AI agent skill for United Nations editorial standards

Creator & maintainer · open source, MIT licence

  • Node.js
  • npm
  • Agent skill
  • CLI
  • Editorial QA

An AI agent skill that reads user-visible copy the way a United Nations editor would: 42 editorial rules covering British English, “per cent” written out, indicator terminology, date formats, numbers, tone and sourcing claims. Installable in one command from skills.sh and published on npm, it reached more than 70 downloads in its first week. The dashboards on this site are checked against it before every publish.

skills.sh/ahaomar/un-editorial-check → github.com/ahaomar/un-editorial-check →

Detail

Contribution
Designed the rule engine and the UN v1 rule profile, with Word, web page and standard-input modes and a security-audit profile that flags dangerous patterns such as innerHTML assignment and eval in agent-generated code.
Hard problem
A dependency scanner flagged the project’s own security test fixture as malicious code. The fixture is inert by construction, so it is now generated at test runtime from harmless fragments — nothing in the repository pattern-matches a dangerous sink.
Why an agent skill
AI writes most first drafts now, including the strings a script generates. The skill puts the editorial standard inside the agent’s loop, so drafts are corrected before a human ever reads them — the same human-in-the-loop governance as the platform work.

10 / 10

tor-to-proposal, AI agent skill for consultant bid preparation

Creator · open source, MIT licence

  • Node.js
  • MCP server
  • Agent skill
  • PDF generation
  • Document automation

A bid tool that refuses to lie: it turns a United Nations or NGO terms of reference (including scanned PDFs through OCR) plus a consultant CV into a verified submission pack — cover letter, tailored CV, technical proposal, financial proposal with visible formulas, compliance checklist and calendar invite. The agent drafts; deterministic tools verify. Every factual claim must trace to a page of the ToR, user input or a cited source, or it stays an explicit placeholder.

skills.sh/ahaomar/tor-to-proposal → github.com/ahaomar/tor-to-proposal →

Detail

Contribution
Built the full pipeline as pure Node.js with no LLM calls at runtime: a CLI router, a 21-tool MCP server and a Claude Code plugin surface, including a dependency-free PDF writer verified by pdf.js round-trip extraction. The test suite spawns the real command line and passes end to end.
Hard problem
Honesty gating. Before a bid pack is built, the rendered client-facing files are re-extracted and re-audited — not the markdown sources — and a pack with a surviving placeholder or an unverified claim is refused with a non-zero exit code.
Availability
Version 2.0.0 on npm; installable as an agent skill with npx skills add ahaomar/tor-to-proposal.
