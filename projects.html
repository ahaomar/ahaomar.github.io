Case studies · six platforms

Systems I architected, still in production.

Each entry is a platform I architected from the ground up — infrastructure, data model and governance logic — not a build I contributed code to. Where the work was a contribution rather than an architecture mandate, it says so.

01 / 06

UN Migration Network Hub

Lead technical architect

  • Drupal 10
  • PHP 8+
  • MySQL
  • Apache Solr
  • Varnish

The central digital platform for the UN system’s engagement on the Global Compact for Migration. It integrates dozens of UN agencies and partners in one secure Drupal 10 ecosystem serving 195 member states and their delegations.

migrationnetwork.un.org →

Detail

Contribution
Architected the platform from the ground up, designing infrastructure for mission-critical workloads. Led technical strategy for custom module development, continuous security patching and zero-downtime version upgrades, coordinating distributed development teams across time zones.
Hard problem
A federated governance model that lets 195 member states and dozens of agencies publish into shared surfaces without data conflicts — each with its own mandate, review chain and provenance requirements.
Recognition
Formal appreciation from IOM Director General António Vitorino for strategic technical contributions at the International Migration Review Forum 2022.

02 / 06

CLIMB — climate, migration & biodiversity data-for-policy tool

Lead architect & developer

  • Drupal
  • PHP 8+
  • PostgreSQL + PostGIS
  • GIS
  • Data visualisation

A full-stack data-for-policy platform that turns environmental displacement research into intelligence G7 and UN decision makers can act on, integrating multi-source climate and migration datasets with interactive GIS layers.

migrationnetwork.un.org/climb →

Detail

Contribution
Architected the backend and database schema from scratch. Designed the APIs and PostGIS spatial queries that process large geospatial datasets, built the ingestion pipelines that harmonise sources, and worked directly with policy experts to translate research into an interface a non-technical delegate can use.
Hard problem
Real-time GIS layer rendering across global datasets without performance degradation, plus validating data accuracy across multiple independent and sometimes disagreeing sources.
Where it landed
Adopted across UN agencies as a reference tool for climate-migration policy, and integrated with the Human Mobility and Climate Change Database.

03 / 06

Global Migration Data Portal

Contributor — dashboards & visualisation modules

  • Drupal
  • PHP
  • MySQL
  • Data visualisation
  • API integration

IOM GMDAC’s public interface for authoritative global migration statistics, serving policymakers, national statistics officers, researchers and the public.

migrationdataportal.org →

Detail

Contribution
Developed key sections of the portal: data ingestion and normalisation pipelines, custom Drupal modules that structure statistical data from dozens of sources without conflict or redundancy, and the interactive dashboards and visualisation modules on top.
Hard problem
Harmonising migration data from competing and overlapping sources, keeping every visualisation accurate under continuous updates.
Scope note
This was a contribution to an existing platform, not an architecture mandate — the distinction matters and the CV states it the same way.

04 / 06

Ahlan Simsim — early childhood development platform

Senior Drupal architect · International Rescue Committee

  • Drupal
  • PHP
  • REST APIs
  • Custom modules
  • Mobile backend

A UNICEF-funded early childhood development programme operating across conflict-affected regions. The backend and mobile APIs serve field teams working in crisis contexts, where platform failure has a humanitarian cost rather than a revenue cost.

Case study engagement — not public facing

Detail

Contribution
Engineered the full Drupal REST API backend powering the mobile field application, deployed across multiple conflict-affected countries, and architected a secure role-based portal letting IRC staff analyse programme data and reallocate resources in real time.
Hard problem
APIs that stay correct on intermittent, low-bandwidth connections, with data integrity and security holding for sensitive humanitarian field data.

05 / 06

UN Migration Network — the Pledging Dashboard

Lead architect & developer

  • Drupal
  • JavaScript
  • GIS mapping
  • Data visualisation

An interactive dashboard visualising global pledges and commitments to the Global Compact for Migration, turning pledge records into country-level visualisation and interactive global mapping for delegations.

migrationnetwork.un.org/the-pledging-dashboard →

Detail

Contribution
Architected the whole path from ingestion to visualisation: a schema flexible enough to model heterogeneous pledge data, mapping integration tuned for real-time updates, and drill-down filtering by country, sector and theme.
Hard problem
Rendering thousands of map data points without performance loss while pledges land live during negotiations — and keeping the interface usable for non-technical diplomats.
Where it landed
Became the tracking tool for global commitments during the International Migration Review Forum.

06 / 06

Moving Voices — interactive migrant storytelling platform

Lead architect & developer

  • Drupal
  • JavaScript
  • Video integration
  • Responsive design

An interactive storytelling platform carrying migrant experience through immersive media and personal narrative — built to connect policymakers and public audiences with the human dimension of migration along the world’s most dangerous routes.

movingvoices.org →

Detail

Contribution
Architected the experience in Drupal with custom modules for video embedding, narrative sequencing and multimedia content management, including 360-degree playback and editorial workflows non-technical storytellers can publish through unaided.
Hard problem
Multimedia that loads reliably across widely varying global connection speeds, with large video assets handled efficiently at scale.
