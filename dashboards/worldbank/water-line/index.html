    Data Sources & Methodology

    Renewable freshwater

    World Bank Indicators API — ER.H2O.INTR.PC: renewable internal freshwater resources, cubic metres per person per year, 2000–2022.

    Scarcity threshold

    The UN water-scarcity line of 1,000 m³ per person per year is used to sort the ledger. Population change does the rest of the work.

    Method

    Every bar, count and takeaway is computed live from the API response on page load. No hard-coded figures.
