    Data Sources & Methodology

    Population aged 65+

    World Bank Indicators API — SP.POP.65UP.TO.ZS: population ages 65 and above, % of total, 2000–2023.

    Old-age dependency

    World Bank Indicators API — SP.POP.DPND.OL: dependents per 100 working-age people.

    Fertility

    World Bank Indicators API — SP.DYN.TFRT.IN: births per woman, latest available year.

    Method

    Every figure is computed live from the API responses. No hard-coded numbers anywhere.
