    Data Sources & Methodology

    Temperature data (live)

    Open-Meteo Historical Weather API — Copernicus ERA5 reanalysis, daily mean temperature 2m, 1940–present. Free, no API key.

    City search

    Open-Meteo Geocoding API (powered by GeoNames) — city names to coordinates, worldwide.

    Method

    "Then" = 1941–1950 mean; "now" = 2015–2024 mean. Distribution chart shows daily means per period. All takeaways computed live from the data.
